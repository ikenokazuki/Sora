# Sora client

Typed TypeScript functions for every Sora tool, for code execution environments. Generated by `bun run gen:client` in the Sora repository; do not edit by hand.

Use it from code that runs next to the model (a sandbox, a script): call a function, filter the result in code, and print only what the model needs. The full result never has to enter the model's context.

```ts
import { searchDeep } from './servers/sora/index.js';

const result = await searchDeep({ query: 'TypeScript 5.5 新機能', limit: 3 });
console.log(result.results.map((r) => `${r.title} ${r.url}`).join('\n'));
```

- `SORA_URL` — the Sora server (default `http://127.0.0.1:3016`).
- `SORA_API_KEY` — sent as `Authorization: Bearer` when the server requires a key.
- Errors are thrown as `SoraError { code, status, retryable, details }`.
- `catalog.json` lists every tool (name, function, category, route). `searchTools(query, 'names')` in `search.ts` finds tools without reading each file.
- Files: `runtime.ts` (HTTP), `search.ts`, `servers/sora/<tool>.ts` (one per tool), `servers/sora/index.ts`, `SKILL.md` (how to use this client, as an agent skill).
