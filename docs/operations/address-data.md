# 住所データ基盤 運用手引（Address Data Operations）

デジタル庁アドレス・ベース・レジストリ（ABR）および日本郵便の一次データを活用した、オンデマンド・市区町村単位の住所データ基盤の構成・設定・運用手引です。

---

## 1. 概要とアーキテクチャ

本機能は、外部のジオコーディング API やサードパーティサービスに過度に依存せず、高精度な住所正規化（住居表示・地番・番地号までの level 8 対応）、郵便番号検索、逆ジオコーディングをローカルで高速に実行するための基盤です。

### 主な特徴
- **ゼロランタイムオーバーヘッド**: サーバー起動時の通信・初期化は一切行わず、使われない環境ではファイル作成や子プロセス起動がゼロです。
- **オンデマンド・市区町村単位の遅延ロード**: 全国一括ダウンロード（数十GB）を行わず、要求があった市区町村（6桁自治体コード単位）のデータのみを順次取得・構築します。
- **軽量な分離子プロセス**: データのダウンロード、ZIP 解凍、CSV 結合、SQLite 構築は、優先度を落とした専用子プロセス（`address-build.js`、nice 10）で実行され、本体サーバーのイベントループやメモリを圧迫しません。
- **自動世代管理とディスク予算**: 一時ディレクトリで検証した後に原子的（atomic）に反映。設定されたディスク予算（既定 2GB）を超過した場合は、最終利用日時が古い市区町村から安全に破棄（LRU evict）します。

---

## 2. 環境変数と設定項目

すべての設定は環境変数経由で行います。設定値はサーバー起動時に読み込まれます。

| 環境変数 | 型 / 選択肢 | 既定値 | 説明 |
| :--- | :--- | :--- | :--- |
| `SORA_ADDRESS` | `lazy` \| `eager` \| `off` | `lazy` | 住所機能の動作モード。<br>・`lazy`: 要求時に必要データのみオンデマンド取得。<br>・`eager`: 共有ジオコーダーでも取得済みローカルデータを積極的に優先。<br>・`off`: 住所データ機能を完全無効化（MCP ツール一覧からも除外）。 |
| `SORA_ADDRESS_DIR` | パス文字列 | `/data/address` または `<db_dir>/address` | 住所データの保存先ディレクトリ。未設定時はデータベースファイルと同階層の `address/` ディレクトリを使用。 |
| `SORA_ADDRESS_MAX_MB` | 数値 (64〜1048576) | `2048` (2GB) | ディスク使用量の上限（MB）。超過時は古い市区町村データから自動回収。 |
| `SORA_ADDRESS_WAIT_MS` | 数値 (1000〜120000) | `20000` (20秒) | 初回データ構築の待機上限（ミリ秒）。上限を超えた場合は暫定結果（`incomplete: true`）を返し、バックグラウンドで構築を継続。 |
| `SORA_ADDRESS_BUILD_CONCURRENCY` | 数値 (1〜4) | `1` | 子プロセスによるデータ構築ジョブの並行実行数。CPU/メモリ負荷を抑えるため既定は 1。 |
| `SORA_ADDRESS_PRELOAD` | 文字列 | `null` | 事前取得する都道府県コード（カンマ区切り、例: `13` や `13,14`、全国は `all`）。 |

---

## 3. ディレクトリ構成と status.json

`SORA_ADDRESS_DIR` 配下は以下の構造で管理されます：

```text
address/
├── status.json                  # 全成果物のメタデータ（版、サイズ、利用日時、エラー記録）
├── lock                         # 構築中ジョブの排他ロックファイル
├── master/<ver>/ja.json         # 全国マスター（都道府県・市区町村・代表点座標）
├── postal/<ver>/postal.sqlite   # 郵便番号・事業所番号・小字対応テーブル
├── index/<ver>/geo.sqlite       # 逆ジオコーディング用町字代表点 RTree 索引
└── city/<lg_code>/<ver>/        # 市区町村ごとのデータ（段A: town.json、段B: 住居表示.txt、地番.txt、範囲表）
```

### `status.json` の確認方法
`status.json` には各成果物の状態が JSON 形式で記録されます：
```json
{
  "artifacts": {
    "master": {
      "ver": "2026-10-13-abc123",
      "checkedAt": 1791880000,
      "usedAt": 1791881000,
      "sizeBytes": 245120,
      "sourceUpdated": "2026-10-02"
    },
    "city:131016": {
      "ver": "2026-10-13-def456",
      "checkedAt": 1791880000,
      "usedAt": 1791882000,
      "sizeBytes": 1823000,
      "sourceUpdated": "2026-09-30"
    }
  }
}
```
- `sourceUpdated`: デジタル庁または日本郵便のデータ提供日。API レスポンスの `dataset.updatedAt` に反映されます。
- `lastError`: 直近の取得失敗情報（HTTP ステータスやタイムアウトなど）。

## 4. データ構築の手動実行と事前取得

通常はオンデマンドで自動構築されますが、コンテナ起動時やバッチ処理で事前に特定市区町村を準備したい場合は、同梱の `address-build.js` を直接実行できます。

### 単体ジョブの手動実行（コンテナ内）
```bash
# 全国マスターの構築
bun /app/address-build.js --dir /data/address --job '{"kind":"master"}'

# 郵便番号データベースの構築
bun /app/address-build.js --dir /data/address --job '{"kind":"postal"}'

# 町字逆ジオコーディング索引の構築
bun /app/address-build.js --dir /data/address --job '{"kind":"index"}'

# 東京都千代田区（131016）の段A（町字）の構築
bun /app/address-build.js --dir /data/address --job '{"kind":"city","lgCode":"131016"}'

# 東京都千代田区（131016）の段B（住居表示・地番・番地号）の構築
bun /app/address-build.js --dir /data/address --job '{"kind":"num","lgCode":"131016"}'
```

終了コード:
- `0`: 正常終了
- `1`: 取得・構築失敗
- `2`: 引数の誤り
- `3`: 国外 IP ブロック等によるアクセス拒否（HTTP 403）

---

## 5. 注意事項とトラブルシューティング

### 国外 IP アドレスによるアクセス制限
デジタル庁アドレス・ベース・レジストリ（ABR）の配信 CDN は、日本国外の IP アドレスからのアクセスに対して HTTP 403 を返却する場合があります。
- 国外 IP からの実行時は、エラーが検知されると指数バックオフ（cooldown）に入り、不要な再試行による負荷を防ぎます。
- API 応答としては `unavailable: [{ artifact: "...", message: "... HTTP 403 (blocked)" }]` または `ADDRESS_DATA_UNAVAILABLE` が返却されます。
- 国外ホスト上で Sora を運用する場合は、`SORA_ADDRESS=off` に設定するか、事前に国内ネットワークで `/data/address` を構築してマウントすることを推奨します。

### ディスク容量の枯渇
- 1 市区町村あたりのデータサイズ目安:
  - 段A（町字）: 数十KB 〜 500KB
  - 段B（住居表示・地番）: 1MB 〜 20MB（大都市の大規模区で最大 30MB 程度）
  - 全国マスター + 郵便番号 + 索引: 約 50MB
- 予算（`SORA_ADDRESS_MAX_MB`）が小さい場合、頻繁に evict と再取得が発生する可能性があります。大都市圏を網羅的に利用する場合は 2GB〜4GB 程度の確保を推奨します。

### 出典とライセンス表示
本機能が出力する住所情報には、以下の一次データの出典が含まれます：
- デジタル庁 アドレス・ベース・レジストリ（クリエイティブ・コモンズ 表示 4.0 国際）
- 日本郵便 郵便番号データ
- 法務省 登記所備付地図データ（地番データ）
MCP ツールおよび REST レスポンスの `attribution` フィールドに適切なクレジットが自動付与されます。
